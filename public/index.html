THE EVIDENCE MODEL

Observed evidence is never confused with interpretation.

Autopsy keeps what systems recorded separate from what a model concludes.

01Observed evidence

Git history, code structure, dependencies, complexity, schema, tests, runtime and deployments.

02Deterministic signals

Historical measurements and bounded classifications derived directly from persisted evidence.

03Grounded interpretation

Model output may reference only evidence keys supplied by the server; unsupported references are rejected.

REPORTS & INTERPRETATION

Evidence first. Interpretation second.

Every useful output points back to the records that make it defensible.

CLAIMS

INTERVIEW

Story scaffolds

INSIGHTS

Bounded AI interpretation

Useful interpretation with visible uncertainty instead of invented intent or causality.

SECURITY & EVIDENCE POLICY

Engineered to be auditable.

Credentials stay server-side, browser sessions are revocable, and the evidence boundary remains explicit.

CREDENTIALS

Protected at rest

Repository credentials are encrypted on the server, never returned by API responses and never placed in worker payloads.

ACCESS

Account sessions

HttpOnly sessions, server-issued CSRF protection and account-scoped repositories keep browser access separate from machine ingestion.

Evidence remains separate from interpretation. Autopsy does not present a heuristic as intent, causality or impact without supporting evidence.
